### Программное обеспечение

Для работы с компонентами рекомендуется использовать браузер, совместимый с WebGL-canvas:

- Google Chrome 104+
- Firefox 106+
- Microsoft Edge 104+
- Яндекс.Браузер 22+

### Аппаратное обеспечение

Наличие аппаратного графического ускорителя.

### Оптимизация производительности при работе с моделями

При работе с BIM-моделями для увеличения скорости загрузки и снижения потребления оперативной памяти  реализована поддержка технологии **OPFS** (частная файловая система страницы браузера).
Технология **OPFS** активируется только при использовании защищённого режима, поэтому для работы с ней необходимо настроить безопасное соединение **HTTPS**.
