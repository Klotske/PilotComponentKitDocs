## ModelPart
Класс позволяет получить информацию о части консолидированной модели.

## Свойства

#### id
Получить идентификатор части консолидированной модели.
```js
get id() : string;
```

#### elementTree()
Получает экземпляр дерева элементов части консолидированной модели.
```js
get elementTree() : ModelElementTree
```

## Методы

#### dispose()
Освобождает ресурсы занятые частью консолидированной модели.
```js
dispose() : void;
```
