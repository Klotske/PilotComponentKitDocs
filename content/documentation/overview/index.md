**Pilot.Web.3D** и **Pilot.Web.2D** -- это компоненты для работы с BIM-моделями и документами. 
Они предназначены для решения задач по отображению моделей и документов в браузерах, 
а также взаимодействию с ними пользователей. Например, они позволяют осуществлять навигацию по моделям и документам при их изучении, 
скрывать элементы модели, менять их цвет, получать свойства, выполнять измерения. Возможна интеграция компонентов в любой веб-сайт, портал или мобильное приложение.
Компоненты **Pilot.Web.3D** и **Pilot.Web.2D** включают в себя библиотеки JavaScript, стили, методы API и документацию.

#### BIM-модели

Для загрузки моделей используйте файлы в формате **.bm** -- это формат работы с BIM-моделями в системе Pilot-BIM (формируется компонентом Pilot-BIM-Server).

#### Документы

Для загрузки документов используйте файлы в формате **.xps** (Open XML Paper Specification, ECMA-388).

### Требования к браузеру

Для работы с BIM-моделями рекомендуется использовать браузер, совместимый с WebGL-canvas:

- Google Chrome 104+
- Firefox 106+
- Microsoft Edge 104+
- Яндекс.Браузер 22+

Для работы с документами рекомендуется использовать браузер:

- Chrome 104+
- Firefox 106+
- Microsoft Edge 104+
- Яндекс.Браузер 22+
