Унифицированные API-интерфейсы Pilot-Cloud позволяют разработчикам создавать приложения, 
которые интегрируются с системой Pilot для расширения ее возможностей в строительной экосистеме. 
Pilot-Cloud — это новое программное обеспечение от АСКОН для управления строительством.
