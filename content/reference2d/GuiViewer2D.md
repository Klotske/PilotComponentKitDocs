**GuiViewer2D** -- это класс для компонента просмотра 2D документов. Он расширяет возможности базового класса <a href="../Viewer2D">Viewer2D</a> и содержит всё, что нужно для отображения и взаимодействия с 2D документами `xps`.

## Методы

### getToolbar()
```js
getToolbar(): ViewerToolbar;
```
Метод получает объект для работы с панелью инструментов. Подробнее: <a href="../ViewerToolbar">ViewerToolbar</a>
