**PilotWeb3D**, **PilotBimDataProvider** и **PilotWeb2D** -- это компоненты для работы с информационными моделями (BIM) и документами, предназначенные для решения задач по отображению моделей и документов в браузерах, взаимодействия с ними пользователей, а также работы с данными информационных моделей. Например, они позволяют осуществлять навигацию по моделям и документам, 
скрывать элементы модели, менять их цвет, получать свойства, выполнять измерения. Возможна интеграция компонентов в любой веб-сайт, портал или мобильное приложение.
Компоненты **PilotWeb3D**, **PilotBimDataProvider** и **PilotWeb2D** включают в себя библиотеки JavaScript, стили, методы API и документацию.

#### Информационные модели

Для загрузки моделей в компоненты **PilotWeb3D** и **PilotBimDataProvider** используются файлы **.bm**, формируюмые сервисом **Pilot-BIM-Server**. Файлы **.bm** -- это контейнер данных информационной модели.
Контейнер информационной модели может содержать как изменение данных относительно предыдущей версии так и актуальное состояние модели, включающее все её изменения до необходимой версии.

#### Документы

Для загрузки документов используйте файлы в формате **.xps** (Open XML Paper Specification, ECMA-388).
