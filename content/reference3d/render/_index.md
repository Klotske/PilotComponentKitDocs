## Отображение моделей
Работа с отображением и взаимодействием с 3D-моделями осуществляется через объект [IRenderViewer3d](./IRenderViewer3d), который можно получить из 
объекта [Viewer3D](../Viewer3D).
```js
  const renderView = viewer3D.renderView;
```
