**ModelElementIds** -- этот класс описывает агрегированный список идентификаторов элементов по части модели.

## Свойства

### modelPartId
Идентификатор части модели.
```js
modelPartId: string;
```

### elementIds
Идентификаторы элементов выборки.
```js
elementIds: string[];
```
